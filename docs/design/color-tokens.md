# Design tokens

The look of the original is simple enough to describe completely, which is why it
could be reproduced without copying any asset: a dark photographic backdrop, a
small gold/orange/blue palette, and cards with a 1 px translucent border.

## Palette

Declared in `app/lib/core/theme/app_theme.dart` as `AppColors`.

| Token | Value | Used for |
|---|---|---|
| `gold` | `#E0A83C` | screen headings, active borders, "LIVE"/status accents, card labels |
| `orange` | `#F5821F` | home tile labels (the default `NavTile` accent) |
| `blue` | `#2C6FBB` | primary buttons, selected sidebar rows |
| `blueDark` | `#1B4C86` | gradient end for tiles |
| `blueTile` | `#1F5FA8` | gradient start for tiles |
| `panel` | `#0B1626` @ 90 % | dialog/menu surfaces |
| `panelAlt` | `#152740` @ 95 % | dialogs, bottom sheets, dropdowns |
| `sidebar` | `#0A1420` @ 80 % | category sidebar and detail panels |
| `divider` | white @ 20 % | hairlines and card borders |
| `textPrimary` | `#E8EFF7` | body text |
| `textMuted` | `#93A7BE` | secondary text, counts, hints |
| `red` | `#D9534F` | errors, expired accounts, non-favourited hover |
| `green` | `#3FA25B` | "watched" ticks, valid expiry |
| `windowBackground` | `#07101C` | the colour the OS window is painted before Flutter draws |

Gradients used in more than one place:

* **Tile** (nav/settings cards): `blueTile → blueDark`, 135°, 1 px border that
  turns gold on hover, hover adds a 14 px glow at 25 % accent.
* **Background scrim**: black at `scrim + 15 %` → `scrim × 50 %` → `scrim + 15 %`
  top-to-bottom, so headings stay readable over any artwork.
* **Channel row**: `black @ 22 %` normally, `white @ 7 %` on hover.

## Type

* Family: Segoe UI (Windows default; keeps the app feeling native).
* Scale: `20` screen heading (w700, 0.6 letter-spacing), `15` detail titles,
  `13.5` playlist/card titles, `12.5` body/rows, `11.5` captions, `10.5` footer.
* Section labels are uppercase `11 px` w700 with `1.0` letter-spacing in gold —
  this is the motif that makes panels read as the original's.

## Space and shape

| Token | Value |
|---|---|
| `Insets.xs/sm/md/lg/xl` | 4 / 8 / 12 / 16 / 24 |
| Card radius | 6–8 (tiles 8, posters 6, rows 4–5, dialogs 8) |
| Grid | `SliverGridDelegateWithMaxCrossAxisExtent`, max 168 px, aspect 0.62, 14 px gaps |
| Sidebar width | 250 px (left), 320 px (right panels) |
| Title bar height | 38 px; window 1280×760, minimum 1024×600 |

## Backgrounds

`assets/branding/bg_*.jpg` are generated by `tools/make_branding.py`: a radial
gradient plus a dot lattice masked by elliptical "landmass" shapes, then a
vignette. Themes differ only in gradient colours, dot colour and spacing:

| Theme id | Inner | Outer | Dots |
|---|---|---|---|
| `main` | `#123660` | `#040A14` | `#78AADC`, 15 px, 125 α |
| `honor` | `#402E10` | `#0A0804` | `#E0A83C`, 16 px, 105 α |
| `black` | `#0E1016` | `#020305` | `#78AADC`, 22 px, 60 α |

Any image works as a background; the scrim adapts, and a missing file falls back
to a blue radial gradient so no screen is ever unreadable.

## Motion

Deliberately minimal, matching a desktop utility:

* hover/press transitions: 140 ms;
* overlay fade in the player: 200 ms; splash → home: 250 ms fade;
* no page slide transitions on the main navigation.
